# 🎫 NOL 예매 알림 봇

1시간마다 NOL 티켓에서 원하는 공연·날짜를 확인해서
- 📢 그 날짜 회차가 등록되고 오픈 시각이 정해지면 한 번
- 🎫 예매가 열리면 좌석 등급별 잔여석과 함께 한 번

텔레그램으로 알려줘요. 매주 월요일 아침엔 지금 추적 중인 공연과 상태를 📌 주간 안내로 보내요.
예매는 직접 해야 해요 (자동 예매 기능 없음).

## 중단하거나 공연 바꾸기 → `settings.txt`
알림 메시지 맨 아래 링크를 누르면 바로 수정 화면이 열려요.
- 중단: `상태: 켜짐` → `상태: 꺼짐`
- 공연 변경: `공연링크 날짜` 줄을 고치거나 추가

`BOT_TOKEN`, `CHAT_ID`
